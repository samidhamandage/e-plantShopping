# e-plantShopping

## Project Description
e-plantShopping is a React-based online plant shopping application where users can explore plants, browse categories, add products to a shopping cart, update quantities, and remove items.

## Technologies Used
- React.js
- JavaScript
- Redux Toolkit
- React Redux
- CSS
- Vite

## Features
- Landing page with Get Started button
- About Us section
- Plant product listing
- Product category filtering
- Add to Cart functionality
- Shopping cart with quantity controls
- Remove items from cart
- Automatic total price calculation
